# Delivery ticket fallback prototype

Interactive concept for **TrackIt + Deliveries** when WAN/telephony fails: company default and plant-level **printed vs digital** ticket delivery.

## Run locally

```bash
cd delivery-ticket-fallback-prototype
npm install
npm run dev
```

## Pages

- **Overview** — current product reality vs gap
- **Company default** — proposed Deliveries setting + hybrid demo toggle
- **Plant overrides** — per-plant force print/digital
- **Batch plant flow** — COMMANDbatch-style print handoff
- **Dispatch view** — effective medium per load

See also `/docs/trackit-deliveries-printed-ticket-fallback.md` for customer-facing research notes.
